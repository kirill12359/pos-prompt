## 6. Объединённые повторы и принятые решения

- «Устройство фундамента» (разд. 2) + «Устройство монолитных ж/б фундаментов (ростверков)» → один файл 090. Различие марок бетононасосов (S 52 SX / S 46 SX) — вариант в поле «механизмы» и в тексте.
- «4. Каменные работы» + «6. Устройство кирпичных стен и перегородок» → один файл 150. Вариант слоистой кладки — условным блоком; толщины — переменные. Дублирующиеся подготовительные операции объединены в один список.
- «Производство работ бетононасосом» и общие требования к бетонированию вынесены в отдельный файл 095; файлы 090 и 130 ссылаются через «требует: ["095"]».
