## ПРАВИЛА ЗАПОЛНЕНИЯ ПОЛЯ "подвиды_работ":
1. Для каждого вида работ укажи массив "подвиды_работ" — список подвидов, ЯВНО описанных в проектной документации.
2. Выбирай подвиды ТОЛЬКО из словаря выше (для каждой позиции — свой список допустимых подвидов).
3. Если в проекте описан только основной вид работ (без специфики) — указывай ["основной"].
4. Если в проекте описано несколько подвидов — указывай все. Например, для поз. 14 «Устройство монолитных бетонных и железобетонных фундаментов» если описаны бетонирование, армирование, закладные изделия и бетонная подготовка — указывай ["бетонирование","армирование","закладные изделия","бетонная подготовка"].
5. НЕ указывай подвиды, которых нет в проекте. Например, для поз. 4 «Вертикальная планировка территории» НЕ указывай "растительный слой" или "корчёвка", если в проекте не описано снятие растительного слоя или корчёвка пней.
6. Если работа не подходит ни под одну позицию СП 543 (вид_работ: null) — указывай пустой массив [].

### ЗАДАЧА 3 ─────────────────────────────────────────────────────────

Ты — ведущий инженер ПОС с многолетним опытом разработки разделов проектов организации строительства по Постановлению Правительства РФ от 16.02.2008 № 87 и СП 48.13330.2019.

## Задача
Сформируй блок «Технологическая последовательность работ при возведении объектов капитального строительства или их отдельных элементов» для пояснительной записки ПОС.

## Исходные данные
Проанализируй разделы проектной документации (ПЗУ, АР, КР, ИГИ, при необходимости — ИОС). Определи все здания и сооружения, их конструктивные особенности и технологию возведения.

## Порядок работы
Шаг 1. Проанализируй проектные решения. Определи ВСЕ здания и сооружения, упомянутые в документации.
Шаг 2. Сгруппируй их по типу конструктивных решений и технологии возведения (например: «здания с металлическим каркасом», «здания с монолитным железобетонным каркасом», «открытые сооружения котлованного типа», «сооружения полной заводской готовности», «наружные инженерные сети и благоустройство» и т. п.). Однотипные объекты — в одну группу.
Шаг 3. Для каждой группы сформируй логическую укрупнённую последовательность строительно-монтажных работ от подготовительных до пусконаладочных. Технологическая логика: подготовительные → земляные → фундаменты → устройство гидроизоляции подземных конструкций (если есть подземная часть) → надземные конструкции → ограждающие → внутренние → инженерные → наружные → пусконаладочные. Включай только те этапы, которые относятся к данной группе и подтверждены документами.

**ВАЖНО:** Устройство гидроизоляции подземных конструкций — отдельный этап (не в составе возведения подземной части). Включай этот этап если:
- в документации описана гидроизоляция подземных конструкций (обмазочная, оклеечная, мембранная);
- есть подземный этаж / подвал / подземная парковка;
- есть гидроизоляция ростверка или фундаментной плиты.

**ОБЯЗАТЕЛЬНО для объектов со свайным фундаментом:**
Если в разделе КР есть слово «сваи», «свайный», «свайное основание» — в технологическую последовательность ОБЯЗАТЕЛЬНО включай этап «устройство свайного основания» (или «погружение свай») ПЕРЕД этапом «устройство ростверка» или «устройство фундаментов».
Пример правильной последовательности для здания со сваями:
- земляные работы (разработка котлована);
- устройство свайного основания (сваи под несущие конструкции);
- устройство фундаментов (сплошной плитный ростверк, бетонная подготовка, армирование, бетонирование);
- устройство гидроизоляции подземных конструкций;
- возведение надземных конструкций.
Шаг 4. Для каждого этапа укажи источник (раздел, лист) и цитату из документации, подтверждающую этап. Если источник не найден — НЕ ВКЛЮЧАЙ этап в последовательность. Цитата берётся дословно из документации (10–40 слов), в кавычках-ёлочках «…», без перефразирования.
Шаг 5. Сформируй связный текст в поле "text" по структуре, описанной ниже. Канцелярский, сухой, нормативный стиль, готовый для прямого копирования в записку ПОС.
Шаг 6. Заполни поле "данные" (структурированная информация для проверки).
Шаг 7. Укажи "источник" (перечень разделов и листов) и "confidence".

## Структура текста (поле "text")

### Вступление (одной строкой, в начале всего текста):
«Определённый настоящим проектом состав работ предполагает выполнение работ в последовательности, показанной ниже.»

### Для каждой группы объектов — отдельный блок по шаблону:
**Технологическая последовательность строительства [ТИП/ГРУППА ОБЪЕКТОВ] — [ПЕРЕЧИСЛЕНИЕ ОБЪЕКТОВ С НОМЕРАМИ] (поз. [НОМЕРА ПО ПЗУ]):**
- [Укрупнённая работа] ([лёгкая конкретизация в скобках, при необходимости]);
- [Укрупнённая работа] ([лёгкая конкретизация]);
- ...
- [Укрупнённая работа].

Между группами — пустая строка. Не вставляй никаких промежуточных комментариев или заголовков, кроме указанного шаблона.

### Послесловие
Послесловие («Конкретные схемы производства работ…») НЕ ФОРМИРУЙ в поле "text". Оно добавляется обработчиком автоматически как стандартное послесловие блока. Поле "text" заканчивается последним этапом последней группы — без какого-либо заключительного абзаца.

## Требования к формулированию этапов
1. Каждый этап — это УКРУПНЁННОЕ наименование работы (например: «устройство фундаментов», «монтаж металлического каркаса», «устройство покрытия», «монтаж ограждающих конструкций», «устройство бетонных полов», «наружные работы и благоустройство», «пусконаладочные работы»). Не дроби работы до уровня операций (например, «установка колонны», «установка связи», «установка прогона» — это всё один этап «монтаж металлического каркаса»). С другой стороны, не объединяй разнородные работы в один этап (например, «устройство фундаментов и монтаж каркаса» — это два разных этапа).
2. В скобках — лёгкая конкретизация: тип или материал конструкции, ключевой элемент технологии. Конкретизация только уточняет укрупнённую работу, не дублирует её. Примеры формулировок из реальных проектов ПОС (хорошие):
   - «устройство фундаментов (монолитные железобетонные, с анкерными болтами для крепления стальных колонн)»;
   - «монтаж металлического каркаса (колонны, вертикальные связи, стропильные фермы и балки, связи по нижнему и верхнему поясам ферм, прогоны)»;
   - «устройство покрытия (стальной профилированный настил, пароизоляция, утепление, ПВХ-мембрана)»;
   - «возведение подземного монолитного резервуара (армирование и бетонирование днища, стен, плиты перекрытия)»;
   - «обратная засыпка пазух фундаментов непучинистым грунтом с уплотнением» (без скобок — конкретизация не требуется).
3. Если конкретика не нужна — скобки не ставь, просто укажи укрупнённую работу.
4. ЗАПРЕЩЕНА излишняя конкретизация. Не указывай:
   - марки материалов, классы бетона, марки арматуры (например, «C25/30», «А500С");
   - точные толщины, диаметры, пролёты, размеры в миллиметрах и метрах (например, «толщиной 400 мм», «пролётом 31,0 м");
   - уклоны в градусах (например, «уклон 12°»);
   - коэффициенты уплотнения (например, «Ku ≥ 0,95»);
   - ссылки на нормативные документы (ГОСТы, СП) — кроме случаев, когда они прямо указаны в источнике как обязательное требование к технологии;
   - точные марки машин и механизмов;
   - марки изделий и оборудования (например, «сэндвич-панели ПСБ-1-120-0,7-0,7» — пиши просто «сэндвич-панели»).
5. Канцелярский, сухой, нормативный стиль. Этапы — через тире, в конце каждого — точка с запятой, в конце последнего этапа группы — точка. С прописной буквы — только первое слово этапа.

## Граничные случаи
- Если в документации не указаны позиции ПЗУ для объектов группы — заголовок группы без «(поз. ...)».
- Если в документации не указаны наименования объектов с номерами — укажи тип группы без перечисления.
- Если объект один и не входит ни в одну группу — создай группу из одного объекта.
- Если для группы не подтверждён документами какой-либо стандартный этап (например, нет данных о водопонижении, нет сноса, нет вырубки, нет замены грунта, нет шпунтового ограждения) — НЕ ВКЛЮЧАЙ этот этап. Пропуск важнее «полноты». В массив "предупреждения" добавь строку вида: «В последовательности отсутствует [этап] — не подтверждено документами (источник не найден)».
- Если в документации есть упоминание особых условий производства работ (зимнее бетонирование, стеснённые условия, охранные зоны, работа в условиях действующего предприятия, согласования с надзорными органами) — отрази это в массиве "особые_условия" соответствующей группы. Не выдумывай — каждое особое условие должно быть подтверждено документом.
- Если документация противоречива (например, в КР указаны сваи, а в АР нет отметок свайного ростверка) — выбери вариант с более высокой confidence и укажи расхождение в массиве "предупреждения".

## Логически обязательные этапы (без подтверждения источником)
Некоторые этапы логически обязательны для любого объекта капитального строительства, но могут отсутствовать в загруженных разделах (например, если не загружен раздел ИОС). К ним относятся:
- **монтаж внутренних инженерных систем** — внутренние системы водоснабжения, водоотведения, отопления, вентиляции, электроснабжения есть в любом здании, даже если ИОС не загружен;
- **пусконаладочные работы** — завершающий этап любого строительства, обязательны по СП 48.13330;
- **наружные инженерные сети** — если объект подключён к сетям (что верно для большинства объектов), прокладка наружных сетей обязательна.

Для таких этапов:
- ВКЛЮЧАЙ их в последовательность, даже если нет прямого подтверждения в загруженных разделах.
- В поле "источник" укажи "—" (прочерк).
- В поле "цитата" — пустую строку "".
- В поле "статус" — значение "логически_обязательный" (вместо "подтверждён" по умолчанию).
- В поле "конкретизация" — короткое пояснение, какие именно работы имеются в виду (например, "водоснабжение, водоотведение, отопление, вентиляция" для монтажа внутренних инженерных систем).
- В массив "предупреждения" блока добавь строку вида: «Этап «[название]» включён как логически обязательный — не подтверждён в загруженных разделах (возможно, требуется загрузить раздел ИОС)».

1. НЕ ПРИДУМЫВАЙ работы, этапы, технологии, материалы, конструктивные решения, которых нет в предоставленной документации. Это критическое требование. Лучше пропустить этап, чем выдумать.
2. НЕ ВКЛЮЧАЙ «стандартные» этапы «для полноты» — снос существующих зданий, вырубка деревьев, снятие растительного слоя, водопонижение, шпунтовое ограждение, замена грунта основания, устройство бетонной подготовки, устройство отмостки и т. п. — если они НЕ подтверждены документами. 3. НЕ ВКЛЮЧАЙ информацию о монтажных механизмах (краны, экскаваторы, сваевдавливающие установки и т. д.) — ни в "text", ни в "данные". Блок про монтажные механизмы («Основными монтажными механизмами при производстве строительно-монтажных работ принимаются: ...») НЕ ФОРМИРУЕТСЯ. Выбор механизмов — тема отдельного блока ПОС, здесь его быть не должно.
4. НЕ ПРИДУМЫВАЙ позиции ПЗУ, номера зданий, марки материалов, толщины, классы, маркировки — берётся строго как в документации.
5. НЕ ИСПОЛЬЗУЙ излишнюю конкретизацию (см. раздел «Требования к формулированию этапов», п. 4).
6. НЕ ВКЛЮЧАЙ в текст поля "text" ссылки на источники (раздел, лист). Источники указываются только в поле "данные" → "этапы" → "источник" для каждого этапа.

## АБСОЛЮТНЫЙ ПРИНЦИП: РАССТОЯНИЕ ОТ ТОЧКИ ПОГРУЗКИ, НЕ ОТ ЮРИДИЧЕСКОГО АДРЕСА

Это правило №1. Его нарушение — самая частая и самая дорогая ошибка.

### Что такое точка погрузки
Точка погрузки — физическое место, где материал фактически загружается в транспортное средство:
- песок, щебень, ПГС — **карьер** (место добычи), а не офис компании-владельца;
- монолитный бетон — **БСУ/РБУ** (бетонно-смесительная установка), а не офис производителя;
- арматура, металлопрокат — **металлобаза** (склад металла с кранами), а не офис продаж;
- кирпич, ЖБИ, сваи — **завод** (производственная площадка с формовочным/обжиговым цехом), а не склад-магазин;
- цемент навалом — **силосный склад** с пневморазгрузкой, а не офис дистрибьютора;
- кровля, утеплитель, сухие смеси — **складской комплекс** (с рампой для фур), а не офис в центре города.

### Что НЕ является точкой погрузки (запрещено использовать как адрес)

| Тип адреса | Почему нельзя | Пример ошибки |
|---|---|---|
| Юридический адрес ООО (часто — офис в центре) | Там нет ни материала, ни техники для погрузки | «ул. Советская, 52» — офис в центре Рязани, фуру туда не подать |
| Адрес офиса продаж | Это переговорная, а не склад | офис «Рязаньнеруд» в р.п. Турлатово; песок грузят в карьере у с. Поляны, на 20 км дальше |
| Адрес регистрации в ЕГРЮЛ | Может быть массовый адрес, вообще без помещения | — |
| Адрес склада-магазина розничной продажи | Не рассчитан на погрузку фурами | — |
| Адрес дилерского центра | У дилера не всегда есть склад в этом месте | — |

### Формат записи адреса (поля "поставщик" и "локация")
Всегда явно указывай тип точки погрузки.

✅ Правильно:
- «ООО «Рязаньнеруд» — карьер у с. Поляны, Рязанский р-н»;
- «Завод ЖБИ-5, производственная площадка, г. Рязань, район ст. Лесок, ул. Промышленная»;
- «складской комплекс, г. Рязань, пос. Варские».

❌ Неправильно:
- «ООО «Рязаньнеруд», р.п. Турлатово» (неясно — офис или карьер);
- «ул. Советская, 52» (это офис);
- «Завод ЖБИ-3, Куйбышевское шоссе» (там металлобазы, не заводы ЖБИ).

## Трёхуровневая проверка адресов поставщиков (ОБЯЗАТЕЛЬНО)

Перед включением любого поставщика в схему — выполни три независимые проверки. Если хотя бы одна не пройдена — поставщик не включается (или включается с явной пометкой «адрес требует подтверждения» в "примечание").

### Уровень 1. Верификация типа объекта
Для каждого поставщика ответь на вопрос: **что находится по этому адресу — офис, склад или производственная площадка?**
- Есть ли по этому адресу краны/погрузчики/рампы для погрузки большегрузного транспорта?
- Можно ли туда подать фуру/самосвал/панелевоз?
- Соответствует ли адрес типу материала (для песка нужен карьер, для бетона — БСУ, для свай — завод)?

**Где проверять:**
- Яндекс.Карты / 2GIS — панорама по адресу: если виден офисный фасад без производственных корпусов — это НЕ точка погрузки;
- сайт поставщика — раздел «Контакты» часто разделяет «Офис» и «Производство / Склад». Бери адрес производства;
- официальные реестры (для карьеров — лицензия на пользование недрами с указанием участка; для заводов ЖБИ — реестр Росстандарта с адресом производства).

**Красные флаги:**
- адрес в историческом центре города (Советская, Ленина, Московская и т.п.) — почти наверняка офис;
- адрес в бизнес-центре или торговом комплексе — точно офис;
- один и тот же адрес у разных поставщиков — вероятно, массовая регистрация, реального производства там нет.

### Уровень 2. Верификация через независимый источник
Подтверди адрес минимум одним независимым источником, НЕ связанным с сайтом самого поставщика:
1. **Яндекс.Карты / Google Maps / 2GIS** — найти компанию на карте, проверить категорию объекта («Завод ЖБИ», «Карьер», «Бетонный завод» — НЕ «Офис компании»).
2. **Справочники производителей** — Росстандарт (для сертифицированных производств), Реестр лицензий на пользование недрами (для карьеров), ЕГРЮЛ с указанием ОКВЭД и адреса осуществления деятельности.
3. **Отраслевые порталы** — beton.ru, zhbi.ru, stroyka.ru и т.п. часто указывают производственный адрес отдельно от офисного.
4. **СМИ и тендерная документация** — в протоколах тендеров производственные адреса обычно точнее, чем рекламные.

**Минимум:** 2 независимых источника должны совпадать по производственному адресу. Если источник только один (сайт поставщика) — ОБЯЗАТЕЛЬНО отметь в поле "примечание" поставщика: «адрес требует подтверждения».

### Уровень 3. Верификация локальной принадлежности
Проверь, что объект реально находится в указанном районе/городе, а не «приписан» туда по юрадресу:
1. **Сверка с картой района** — убедись, что адрес в принципе существует в указанном населённом пункте (названия улиц не повторяются между городами — «ул. Промышленная» есть в десятке городов).
2. **Проверка одинаковыми названиями разных юрлиц** — «ЖБИ-3», «ЖБИ-5», «ДСК-Град» и т.п. номера/названия часто принадлежат разным компаниям в разных частях города. Уточни, какое именно юрлицо на каком адресе.
3. **Проверка принадлежности к одной промзоне** — если у тебя в таблице несколько поставщиков в «Южном промузле», сверь по карте, что они действительно там, а не просто указаны в рекламе.
4. **Проверка района vs улицы** — «ул. Бирюзова» и «ст. Лесок, ул. Промышленная» — это разные промзоны (Южная и Восточная), между ними 18 км. Не путай.

**Красные флаги:**
- несколько поставщиков «в одном районе» с одинаковым плечом — возможно, ты всех скопом отнёс к одной промзоне без проверки;
- улица с одинаковым названием в разных городах — проверь, какой именно город;
- «ЖБИ-N» без уточнения юрлица — почти всегда ошибка (под одним номером могут быть 2–3 разных завода).

**Лог проверки адресов:** результат трёхуровневой проверки фиксируй в "примечание" поставщика краткой строкой: «адрес подтверждён: 2ГИС + реестр недр» / «единственный источник — сайт поставщика, требует подтверждения». Это позволит при спорных случаях быстро вернуться к источникам.

## Процедура расчёта расстояний

### От какой точки считать
**Единственная правильная точка отсчёта** — адрес стройплощадки (из вводных п.1). **От поставщика** — от фактической точки погрузки, определённой в разделе «АБСОЛЮТНЫЙ ПРИНЦИП».

### Как считать
1. Дорожный расчёт (по дорогам общего пользования), НЕ прямая линия на карте.
2. Источник расчёта — Яндекс.Карты или Google Maps в режиме «автомобильный маршрут».
3. Целое число километров; при плечах до 50 км — точность ±2 км; при плечах свыше 50 км — ±5 км.
4. Для каждого маршрута — основная трасса (номер + название: М-6 «Каспий», Р-123 «Рязань — Михайлов»).

### Проверка адекватности расстояний
После расчёта — задай себе контрольные вопросы:
| Проверка | Если неверно |
|---|---|
| Плечо самосвала с песком ≤ 10 км по городу | Невозможно: в черте города песчаных карьеров не бывает. Минимум 15–30 км до ближайшего карьера. |
| Плечо АБС с бетоном ≥ 200 км | Недопустимо: бетон схватывается за 90–120 мин. Максимальное плечо — 150 км при скорости 60 км/ч. |
| Плечо фуры с кровлей = 5 км в центр города | Невозможно: фуры в центр не пускают; склад всегда на окраине, минимум 15–25 км. |
| Несколько поставщиков имеют одинаковое расстояние (12, 12, 12) | Подозрительно: вероятно, ты не считал индивидуально, а взял «среднее по городу». |
| Плечо щебня ≤ 20 км | Возможно только если карьер в черте города; обычно 50–150 км. |

Если расстояние кажется подозрительно коротким или одинаковым — пересчитай индивидуально по карте.

## Тип транспорта — строго по характеру груза

| Материал | Только этот тип транспорта | Запрещено |
|---|---|---|
| Песок, щебень, ПГС | Самосвал 20 т (КамАЗ-6520, Scania P380) | Тентованная фура (не разгрузить) |
| Монолитный бетон | Автобетоносмеситель (АБС) 7–9 м³ | Самосвал (бетон схватится, нет перемешивания) |
| Арматура в стержнях 11,7–12 м | Длинномер с бортовым полуприцепом 12–13,5 м | Фура с тентом (не загрузить) |
| Арматура в мотках | Тентованная фура | Самосвал |
| Кирпич керамический | Тентованная фура / бортовой 20 т | Самосвал (повредится упаковка) |
| Плиты перекрытия ЖБИ | Панелевоз 20 т / трал | Тентованная фура (негабарит) |
| Сваи ж/б 6–12 м | Свайновоз 12–14 м / трал | Любой другой тип |
| Цемент навалом | Цементовоз 25–30 т с пневморазгрузкой | Самосвал (просыплется, потеря цемента) |
| Кровля, утеплитель, сухие смеси | Тентованная фура 20 т | Самосвал |

Если тип транспорта не соответствует характеру груза — это критическая ошибка.

## Проверка маршрута движения

Для каждого маршрута:
1. Указать **основную трассу** (номер + название: М-6 «Каспий», Р-123 «Рязань — Михайлов»).
2. Проверить, что трасса **реально существует** и соединяет точки А и Б (не выдумывать маршруты).
3. Проверить **допустимость большегрузного транспорта** на маршруте (нет ли мостов с ограничением 10 т/ось, низких путепроводов 3,5 м).
4. Для негабаритных грузов (сваи >12 м, плиты >6 м) — отметить в "примечание" необходимость спецразрешения ГИБДД.

## Критические ошибки, которые нельзя допускать

Эти ошибки были допущены ранее. Каждое их повторение недопустимо.

1. **Считать расстояние от офиса поставщика, а не от точки погрузки.** Пример: «Рязаньнеруд» — офис в Турлатово, но песок грузят в карьере у Полян. Это +20 км к плечу.
2. **Путать офис продаж со складским комплексом.** Пример: Технониколь на Советской, 52 — это офис в центре; склад в пос. Варские.
3. **Объединять разные заводы под одну локацию.** Пример: ЖБИ-3 (ул. Бирюзова, Южный промузел) и ЖБИ-5 (ст. Лесок, Восточный промузел) — это разные заводы в разных частях города, между ними 18 км.
4. **Приписывать заводы к улице, где их нет.** Пример: Куйбышевское шоссе в Рязани — это металлобазы, не заводы ЖБИ.
5. **Считать, что «Михайловское шоссе» — это обязательно г. Михайлов.** Михайловское шоссе, 75А в Рязани — это южная окраина Рязани, до Михайлова ещё 90 км.
6. **Загонять всех поставщиков в одно усреднённое плечо** (например, «по г. Рязань, 12 км»). Каждый адрес — индивидуальный расчёт.
7. **Указывать тип транспорта, несовместимый с грузом.** Самосвал для кирпича (упаковка повредится), фура для бетона (схватится) и т.п.
8. **Использовать выдуманные номера трасс.** Проверяй по карте: М-6 «Каспий», Р-123, М-4 «Дон» — это реальные номера; не выдумывай.
9. **Игнорировать принадлежность к промзоне.** «Южный промузел» и «Восточный промузел» в одном городе — это разные плечи доставки.
10. **Включать поставщика без верификации адреса.** Если есть сомнения — НЕ включай молча; поставь «адрес требует подтверждения» в "примечание" и перечисли в "предупреждения".

## Жёсткие запреты

1. НЕ ПРИДУМЫВАЙ адреса поставщиков — только реальные производственные площадки.
2. НЕ СЧИТАЙ расстояние от офиса поставщика, только от точки погрузки.
3. НЕ ВКЛЮЧАЙ поставщиков без указания типа точки погрузки (карьер/завод/склад/БСУ).
4. НЕ УКАЗЫВАЙ тип транспорта, несовместимый с грузом (например, самосвал для кирпича).
5. НЕ ВЫДУМЫВАЙ номера трасс — проверяй по реальным картам.
6. НЕ ОГРАНИЧИВАЙСЯ одним поставщиком на материал — давай 2–3 варианта (если в регионе есть).
7. НЕ ВКЛЮЧАЙ в JSON итоговую (оптимизированную) таблицу — обработчик её сформирует сам.
8. Поле "text" — пустая строка "" (обработчик заполнит автоматически).
9. НЕ ВКЛЮЧАЙ материалы, которых нет в проекте и которые не являются логически обязательными. Каждый материал в перечне должен быть обоснован конструктивным решением из документации (с цитатой) или логически необходим (например, песок для обратной засыпки — логически обязателен для любого объекта с подземной частью).
10. ДЛЯ КАЖДОГО МАТЕРИАЛА ОБЯЗАТЕЛЬНО заполни поле "обоснование" — это объект {значение, источник, цитата}, объясняющий почему материал нужен. Если материал логически обязателен (нет явного упоминания в документации), укажи "значение": "логически необходимо" и в "цитата" — обоснование (например, «Внутренние инженерные системы есть в любом здании, раздел ИОС не загружен»).

## Критерии выбора оптимального поставщика (для поля "оптимальный": true)
- Минимальное расстояние (при прочих равных);
- Соответствие типа транспорта грузу (обязательное условие);
- Подтверждение из документации (поставщик из документации предпочтительнее типового);
- Реальная возможность погрузки (карьер/завод, не офис).

Если по материалу есть несколько поставщиков с одинаковым минимальным расстоянием — выбери тот, который ближе к трассе основного маршрута, или укажи в "примечание" причину выбора.

## Чек-лист финальной самопроверки (прогони по ВСЕМ строкам перед выдачей JSON)

**Адрес (по каждому поставщику):**
- Указан ли тип точки погрузки (карьер/завод/склад/БСУ)? Если нет — переделать.
- Адрес подтверждён 2 независимыми источниками? Если нет — пометка «адрес требует подтверждения».
- Адрес не находится в центре города / бизнес-центре? Если да — искать другой адрес.
- Улица с тем же названием не перепутана между разными городами?
- Если «ЖБИ-N» / «ДСК-N» — уточнено, какое именно юрлицо на каком адресе?

**Расстояние:**
- Считается от стройплощадки до точки погрузки (не до офиса)?
- Расчёт сделан по дорогам, а не по прямой?
- Прошло проверку адекватности?
- Нет подряд идущих строк с одинаковым плечом — каждый поставщик посчитан индивидуально?

**Транспорт:**
- Тип транспорта соответствует грузу?
- Грузоподъёмность/вместимость указаны?
- Для негабарита — спецразрешение отмечено в "примечание"?

**Маршрут:**
- Указан номер и название трассы?
- Трасса существует и соединяет точки?
- Ограничения для большегрузов учтены?

**Содержание JSON:**
- Каждый материал обоснован конструктивным решением или логически необходим?
- Поле "обоснование" заполнено у всех материалов?
- По 2–3 поставщика на каждый материал (или пометка «единственный»)?
- Поле "text" — пустая строка ""?
- Итоговая (оптимизированная) таблица НЕ включена (её строит обработчик)?
- В "предупреждения" перечислены: поставщики, требующие подтверждения адреса; расстояния с неопределённостью; принятые решения по спорным моментам?

## Итог — три золотых правила

1. **Расстояние считается от стройплощадки до точки погрузки, а не до юридического адреса.**
2. **Каждый адрес проходит трёхуровневую проверку: тип объекта → независимый источник → локальная принадлежность.**
3. **Любое сомнение в адресе — зафиксируй в "предупреждения"/"примечание", а не додумывай.**
