# INDEX — библиотека технологий работ для ПОС

Версия библиотеки: 1.0 · Дата: 2026-11-22

## Как пользоваться (для ИИ-агента, формирующего ПОС)

1. Включи все технологии с «Обязательная = да».
2. По каждой остальной сверь «Когда включать» и «Не включать, если» с данными объекта (ПД/JSON). Включай только при подтверждении в ПД и указывай документ/лист-основание.
3. Учти «Требует» (включить зависимые) и «Исключает».
4. Вставляй выбранные технологии в порядке кода.
5. Переменные {{T.…}} заполни из ПД; без данных и без значения по умолчанию выдели место красным. Условные блоки [ЕСЛИ: …] оставь только при выполнении условия, маркеры удали.
6. Файлы со статусом «черновик» используй, но отметь в сопроводительном сообщении.

## Как добавить технологию (для пользователя)

Выберите свободный код (шаг 10 между существующими: например, 215 между 210 и 220), скопируйте шапку YAML из существующего файла, заполните поля «когда_включать», «не_включать_если», «признаки_в_пд», «механизмы», «нормы», «переменные», «акты_скрытых_работ», задайте статус «черновик». Опишите технологию (разделы ## и ###, перечисления через «- », переменные {{T.…}}). Добавьте строку в таблицу «Перечень технологий» этого файла, при необходимости — строки в таблицы переменных и условий. Увеличьте версию библиотеки.
